プライバシーポリシー / Privacy Policy

制定日: 2026年10月12日 / Effective: October 12, 2026

1. 何をするアプリか

Company Video Publisher(以下「本アプリ」)は、運営者が自分の YouTube チャンネルを管理するためだけに使う道具です。運営者以外の人のアカウントでは使いません。

2. 使うデータ

本アプリは、運営者が Google の許可の画面で認めた範囲で、YouTube Data API と YouTube Analytics API を通じて、運営者のチャンネルの情報(チャンネル・動画・再生リスト・字幕・チャンネルの表示の設定・再生などの数字)を読み書きします。

3. 使い道

運営者自身のチャンネルへの動画の投稿と予約、再生リストとチャンネルの表示の管理、数字の確認のためだけに使います。広告や、ほかの目的には使いません。

4. 保存と共有

許可の情報(トークン)と数字は、運営者の手元のコンピューターにだけ保存します。第三者に売ったり、渡したり、公開したりしません。

本アプリが Google API から受け取った情報の使い方と受け渡しは、制限付き使用の要件を含め、Google API Services User Data Policy に従います。

5. 許可の取り消し

許可はいつでも Google アカウントの「サードパーティのアプリとサービス」 から取り消せます。

6. YouTube と Google の規約

本アプリは YouTube API サービスを使っています。YouTube の利用には YouTube 利用規約 が、データの扱いには Google プライバシー ポリシー が適用されます。

7. お問い合わせ

GitHub の Issues へどうぞ。

English summary. Company Video Publisher is a private uploader for YouTube, used only by its operator to manage the operator's own YouTube channels. With the operator's consent it accesses channel, video, playlist, caption, branding and analytics data through the YouTube Data API and YouTube Analytics API, only to upload and schedule videos, manage playlists and channel presentation, and review statistics. Tokens and statistics are stored only on the operator's own computer and are never sold, shared or published. This app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions. Use of YouTube is subject to the YouTube Terms of Service, and data handling is subject to the Google Privacy Policy. Contact: GitHub Issues.
